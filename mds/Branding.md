# Branding

## Identity
Clean, minimal, architectural. Let the photography lead. No decoration, no noise.

## Colours
| Token | Hex | Use |
|-------|-----|-----|
| Black | #111 | Text, nav, headings |
| Mid | #555 | Body text, descriptions |
| Border | #e8e8e8 | Dividers, nav border |
| White | #fff | Page background |

## Typography
- Font: Helvetica Neue, Helvetica, Arial (system sans-serif stack)
- Headings: weight 600, ~36px
- Project titles: weight 500, ~28px
- Body: weight 400, 15px, color #555
- Nav: 13px, #111
- Gallery arrows: 48px, weight 700

## Layout principles
- Generous whitespace
- Photography always full-width when focused
- No cropping — images shown at natural dimensions
- Two-column paired layout for project galleries
- Mobile: single-column scroll gallery

## Do not
- Add decorative elements
- Change the font stack
- Use colours outside the palette
- Add gradients, shadows, or overlays to photos
